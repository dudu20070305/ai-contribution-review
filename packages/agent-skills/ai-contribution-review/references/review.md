# 争议、复核与使用边界

## 一、四类争议

| 类型 | 典型情形 | 处理路径 |
|---|---|---|
| 事实争议 | 「这段是我写的，不是 AI 写的」 | 核对段落溯源记录，双方共同查看原话 |
| 等级争议 | 「我这句质疑应该算交互，不算主动」 | 核对 R3 判据，看是否有理由支撑 |
| 分档争议 | 「我用中文说，但说的是英文用法」 | 不改档，记入补充观察 |
| 用途争议 | 「这份报告被拿去当处分依据」 | 按第四节处理：报告不具此效力 |

## 二、学生异议程序

1. 学生收到报告后 **7 日内**可对任一判定提出异议，须指出具体条目与理由。
2. 异议不要求提供证据，但提供证据的异议优先处理。
3. 教师须在 7 日内答复，说明「维持」或「修改」及其依据。
4. 异议与答复均记入 `disputes`，随报告保存。

## 三、教师复核程序

复核不是重新判定，是**核对判定是否有据**。

| 步骤 | 动作 | 通过标准 |
|---|---|---|
| 1 | 抽查 3 条环节判定 | 每条均有原话引用与轮次 |
| 2 | 抽查 2 条降级判定 | 每条均注明缺失的证据类型 |
| 3 | 核对四项门槛 | 每项均说明检索范围 |
| 4 | 核对不确定性 | 四类标注与实际相符 |

通过 → `review_status` 改 `reviewed`，页脚变「已复核」。不通过 → 退回重算，或标「存疑」。

## 四、使用边界

**报告不具以下效力**

- 不作为处分、评优、升学的依据；
- 不进入学校档案系统；
- 不用于学生之间的比较或排名；
- 不向第三方提供。

**理由**：报告是自证工具，证据强度不足以支撑高利害决定。若用于处分，后果的严重性与证据的强度不匹配，效度论证失败。

一旦报告被当作分数使用，学生行为会向指标靠拢，指标测量的东西随之消失。这是本方案最大的风险，也是划这条边界的直接原因。

## 五、分歧未决的处理

判定者之间无法达成一致时，**不强行归类**：

- 该条目标「存疑」，并列两种读法及各自理由；
- 存疑条目不计入门槛判定；
- 报告中说明存疑条目数。

这不是缺陷。真实场景中代打字、换设备、家长协助都很常见，强行归类会制造误判。

## 六、信度报告

若做多评判者对照，应报告 Cohen's kappa，并注意两点：

1. **基准是惯用的，不是绝对的。** 0.61–0.80 被标为「实质性一致」，但该组界值被原作者明确说明为任意且非普遍接受，且 kappa 受类别数与样本量影响。本方案只有四个等级，类别少会使 kappa 偏高。
2. **不得以最大化 kappa 为目标调参。** kappa 衡量的是与参照判断的一致性，不是效度；以一致性为目标拟合，得到的是与参照者先验的吻合度。

分析单元须固定为「段落」与「环节」，否则评分者间信度无法计算——这是内容分析方法的既有教训。
