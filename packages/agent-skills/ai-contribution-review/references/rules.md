# 判定规则 R1–R5

规则版本 1.0。与 `scripts/rules.py` 中的常量一一对应，改动须同步两侧。

规则之间刻意独立：**R1 与 R2–R4 并行计算，互不输入；R5 只读 R2–R4 与追问记录，不读 R1。** 任何一项都不能用来修正另一项。

```
R2 划环节 ──→ R3 判等级 ──→ R4 验证据 ──→ 环节 × 等级矩阵
                                              │
R1 算文本归属 ────────────────────────────────┤
                                              ├──→ R5 四项门槛 ──→ 标签组
学习证据（追问记录）──────────────────────────┘
```

## R1　文本产出归属

按段落判：这段文字相对 AI 输出发生了什么层级的改动。

| # | 学生对这一段做了什么 | 语言条件 | 权重 |
|---|---|---|---|
| 1 | 直接采用 AI 输出，未改动 | — | 0% |
| 2 | 只提要求、由 AI 自行修改（「正式一点」） | — | 10% |
| 3 | 口头给出要点，AI 跨语言成文 | 学生用母语口述 | 25% |
| 4 | 指定替换具体内容（换例子、换数据、加经历） | 学生给出目标语内容 | 35% |
| 5 | 口头给出要点，AI 同语言组织成文 | 学生用目标语言口述 | 45% |
| 6 | 自己重写该段 | — | 80% |
| 7 | 自己撰写，AI 未参与 | — | 100% |

全文按字数加权平均，得「加权归属率」。来源不明的段落移出分母。

**第 2 档为什么只有 10%**：只下指令不改内容，对应「简单转述不算学业成果」的规范红线。

**第 3 档为什么低于第 4 档**：这条轴的主序是**语言参与度**，不是内容量。第 4 档的学生在目标语言内部工作，能判断替换后的表达对不对；第 3 档的学生在目标语言之外工作，无法判断 AI 的表达。

**第 3 档的三个启用前提**

1. 仅当教学目标包含目标语言产出时启用。若语言只是载体（如「读懂材料并表达观点」），二语水平属构念无关变异，下调会污染测量。此前提由教师布置作业时声明。
2. 只看语言是否一致，不做能力评估。学生用母语构思、AI 产出目标语，即适用 25%，不追问「他其实能不能自己写」。
3. 报告须区分两类低分：「参与不足」与「跳过了语言层」，教学处置完全不同。

**已知边界情形**：学生用母语口述，但口述内容本身是对目标语的判断（「不要用 delicious 这个词，太简单了」）。按字面规则仍计 25%，不改档，但记进补充观察。规则宁可保守，也不在缺乏依据时增设例外档。

## R2　六个决策环节

环节须可分离、可穷尽、可观察。按 E1→E6 顺序扫读，每环节只记首次实质性介入。

| 环节 | 判定范围 | 理论位置 |
|---|---|---|
| E1 任务定义 | 题目、对象、字数、文体、禁忌 | 自我调节第一阶段的任务定义 |
| E2 素材与信息提供 | 学生注入的具体信息、例子、经历、数据 | 内容问题空间 |
| E3 结构与论证设计 | 段落安排、论点顺序、论证策略 | 修辞问题空间 |
| E4 校验与纠错 | 指出 AI 的具体错误、否定方案、要求重做 | 写作三大基本过程之「复查」 |
| E5 最终取舍与定稿 | 明确采纳或否决、比较多个版本 | 评价性判断 |
| E6 元认知调控 | 对自身理解、策略、进度的表述与调整 | 元认知独立维度；适应性调节 |

**E6 为什么必须单列**：三处独立来源指向同一处——内容分析框架把元认知列为与认知并列的维度；自我调节模型的第四阶段是「适应」；分类学把元认知知识列为独立知识类型。跑测中最有价值的干预之一是对课程目标的理解（「我们课叫英语文学导论，所以论点应该讨论某种手法」），前五环节无处安放。

**E6 的验证**：须引用原话，且须含对任务或策略的判断。只表达情绪（「好难」「我不懂」）不计入。

多次介入同一环节时取深度最高的一次，`note` 注明次数。

## R3　ICAP 四级

| 等级 | 行为判据 | 对话中的典型表现 |
|---|---|---|
| P 被动 | 无超出所给材料的产出，仅接收 | 「好的」「继续」「可以」；原样接受 |
| A 主动 | 在给定材料内操作，无新增内容 | 在选项中挑一个；替换词句；调整顺序 |
| C 建构 | 产出超出所给材料的内容 | 自己的例子、不同论点、AI 不可能知道的信息 |
| I 交互 | 双方发言均为建构性且有充分轮次交替 | 指出具体错误并给理由；否决并要求重做；多轮澄清 |

**C 的判据**来自原文「产出超出所给学习材料的、外化的输出或产品」；**I 的判据**须同时满足：双方发言都具建构性质、有足够轮次交替。

由这两条可直接推出：学生只说「好的」「继续」时，其发言非建构性，不满足第一条件，故不成立交互，只能计 P。

**等级是序数，不是分数**：不加总、不平均、不换算百分制，报告以矩阵呈现。若要比较，只能比「同一环节的等级变化」或「同一等级的环节数量」。

**构念差异必须承认**：ICAP 原本测学习投入的深度，本方案用它判决策深度，属借用。决策深度是学习深度的必要而非充分条件。报告不得把等级解释为「学习效果」。

## R4　证据校验

行为上达到 C 或 I，但无法提供下列任一证据时，**降一级**。

| 证据类型 | 追问 | 合格回答 | 不合格回答 |
|---|---|---|---|
| 来源可溯 | 这个内容是哪来的？ | 可指认具体出处（经历、材料、数据） | 「就是想到了」 |
| 理由可述 | 为什么这么改？ | 说出判断依据（规则、事实、效果） | 「感觉这样好」 |
| 质量可辨 | 为什么不要那一版？ | 指出具体缺陷（样本小、论证跳跃、用词不当） | 「不太喜欢」 |

**操作**：初判 → 若为 C 或 I，检索三类证据 → 有则维持并引用原话 → 无则降一级（C→A，I→C）并注明缺失的证据类型 → 学生拒答或答非所问按「无」处理。

**每条降级须记录三项**：原等级、降级后等级、缺失的证据类型。

降级机制的作用是**提高刷分成本**，不是消除可能。学生仍可事先准备理由；方案不承诺识别所有表演性互动。

## R5　四项门槛

加权求和的前提（偏好独立、加性独立）在六环节之间不成立，改为非补偿性结构：某项未满足，不能被其他项的优异表现抵消。

| 编号 | 门槛 | 满足的判据 | 未满足的标签 |
|---|---|---|---|
| K1 | 有可复核的校验 | 至少一次指出 AI 的具体错误并说明理由（E4 达 I 且有证据） | 未经验证 |
| K2 | 有内容增量 | 至少一处 AI 不可能知道的信息（E2 达 C 且有来源） | 无私有信息 |
| K3 | 有明确取舍 | 至少一次明确指出采纳或否决的理由（E5 达 A 以上且有理由） | 默认全收 |
| K4 | 有自我监控 | 至少一次对自身理解或策略的判断（E6 达 A 以上） | 无自我监控记录 |

四项独立判定，输出四个标签的组合，**不合成**。每个「满足」附原话；每个「未满足」说明检索范围。

标签不是缺陷清单，是教学起点：

| 缺项 | 可能的教学含义 | 建议动作 |
|---|---|---|
| 缺 K1 | 未形成验证习惯 | 下次任务专设「找错」环节 |
| 缺 K2 | 未注入个人经验 | 检查任务是否允许个人化 |
| 缺 K3 | 未做取舍判断 | 要求提交两版并说明选择理由 |
| 缺 K4 | 无自我监控 | 加入「先写提纲再说思路」的步骤 |

## 附：边界判例

**已定的情形**

| 情形 | 判定 |
|---|---|
| 「好的」「继续」「可以」 | P |
| 「第二个」——只选不定 | A |
| 「把 wonderful 改成 quiet，因为那天早上很安静」 | 归属第 4 档；环节 E3/E5 仍为 A（在给定版本内操作） |
| 「we was 写错了，应该是 we were」 | E4 达 I（指出具体错误 + 给出正确形式） |
| 「我们课叫英语文学导论，所以论点应该是讨论某种手法」 | E6 达 C（对课程目标的理解，非 AI 可推知） |
| 「用中文说不要用 delicious」 | 归属仍第 3 档，记补充观察 |

**方案未定、须标「存疑」的情形**

| 情形 | 两种读法 |
|---|---|
| 「给我解释一下什么叫可证伪性」 | 一：属接收材料，计 P；二：提出了明确的知识缺口，接近 C |
| 「这个提示词明显显示你干太多了」 | 一：属 E5 取舍判断；二：属 E6 对学习过程的监控。环节归属未定 |
| 「能不能换个说法，这个太生硬了」 | 一：句法层替换，属 A；二：说明了判断理由，属 C |

标「存疑」时在 `note` 并列两种读法及理由，且该环节不计入门槛判定。**不强行归类**——真实场景里代打字、换设备、家长协助都很常见，强行归类会制造误判。
