# 学生作业 AI 使用与学生自主贡献判读

把一次「学生 + AI 共同完成作业」的会话，判读成教师 30 秒能读完的一页报告。报告给三类读数，不给总分。

前提：作业在当前会话内完成，过程可见。本 skill 不推测、不检测、不还原学生在别处做了什么。

## When to use　什么时候用

满足任一条件时使用：

- 学生在用 AI 做完作业后说「出报告」「生成评价」；
- 教师要求评价某次 AI 辅助作业的过程；
- 教师拿到会话记录与终稿，要做过程复核。

不要在以下情形使用：作业已完成于别处且无会话记录（只能走「记录缺失」路径，见步骤 3）；只需要给作文打分（那是结果评价，不是本 skill 的范围）。

## Input　输入

| 输入 | 是否必需 | 缺省处理 |
|---|---|---|
| 会话记录（学生发言与 AI 输出的全部轮次） | 必需 | 无记录 → 转「记录缺失」路径 |
| 终稿或明确的最后一版 | 必需 | 请学生提供 |
| 目标语言 | 必需 | 问教师，不要猜 |
| 教学目标是否包含目标语言产出 | 必需 | 未声明按「否」处理，并在不确定性中注明 |
| 任务类型（写作／阅读／语法练习） | 必需 | 问教师 |

第二项决定第 3 档（跨语言成文，25%）能否启用。猜错会直接改变结论。

## Steps　步骤

1. **读任务规范。** 取目标语言、教学目标、任务类型。缺目标语言 → 停止并询问。输出：`meta` 五个字段。
2. **解析对话。** 切成「学生发言／AI 输出／编辑动作」三元组，标轮次与语言。记录不完整 → `record_completeness: partial`。输出：轮次表。
3. **判断证据是否足够。** 无生成与修改过程 → 转「记录缺失」：`report_mode: no_record`，段落留空，六环节记「未涉及」，四项门槛 `met: null`，**不运行计算脚本**。输出：模式判定。
4. **段落溯源。** 终稿按自然段切分，逐段匹配到 AI 输出的具体轮次，判定改动层级；匹配不到 → `tier: null`、`traceable: false`，移出分母。不得凭语义相似度硬配。输出：段落记录。
5. **算归属。** 运行 `python scripts/compute_attribution.py analysis.json --write`。七档权重由脚本按 `scripts/rules.py` 计算，不要手算。输出：加权归属率与三段占比。
6. **识别六环节。** 按 E1→E6 顺序扫读，每环节只记首次实质性介入；多次介入取深度最高的一次并在 `note` 注明次数。输出：环节清单。
7. **判等级并验证据。** 先判 ICAP 初判等级；若为 C 或 I，检索三类证据之一（来源可溯／理由可述／质量可辨）。有 → 填 `evidence_type` 与原话；无 → 降一级（C→A，I→C），填 `downgrade_reason` 与 `missing_evidence`。输出：环节 × 等级矩阵。
8. **判四项门槛。** K1 可复核的校验、K2 内容增量、K3 明确取舍、K4 自我监控，四项独立、互不抵消，每项必须写 `search_scope`。输出：四个标签。
9. **生成并校验。** 写完整 `analysis.json`（字段见 `references/report-spec.md`），依次运行：
   `python scripts/validate_report.py analysis.json`（必须零 ERROR）
   `python scripts/render_report.py analysis.json`（出单页 HTML）
   输出：`<作业名>-report.html`。

## Constraints　约束

**四条红线**（违反任何一条，报告即失效）：

1. 不算总分，不做加权求和。等级是序数，不加总、不平均、不换算百分制。
2. 不做 AI 文本检测。通用检测器对非母语写作者有系统性偏差，且本场景文本本就主要由 AI 产出。
3. 缺证据不下判断。没有原话就不判等级，没有过程记录就不出读数。写「无法评价」优于推测。
4. 不用于处分、评优、升学、排名，不向第三方提供。页脚已固定印上这句，不要删。

**其他必须遵守**：

- 降级只允许一级（I→C、C→A），不得跨两级。
- 判不准时标「存疑」并列两种读法，不二选一硬判；存疑条目不计入门槛。
- 校验器报错就改 JSON，**不要改校验器**。
- 结论句引用具体行为，不写「表现良好」「优秀」这类总体评价。
- 学生姓名等可识别信息一律脱敏为「学生A」。
- 会话记录须随报告一并提交，这是自证工具的取证要求，不是可选项。

## Acceptance　验收

全部满足才算完成：

- [ ] `validate_report.py` 零 ERROR
- [ ] 报告为 1 页 A4（浏览器打印预览确认，或 `msedge --headless=new --print-to-pdf` 后数页数）
- [ ] 每条 C/I 等级都能指到一句原话与轮次
- [ ] 每个降级都写了缺哪类证据
- [ ] 四项门槛都写了检索范围
- [ ] 四类不确定性（溯源／判定／输入／复核）都填了
- [ ] 结论句有具体行为，无评价性措辞
- [ ] 页脚保留规则版本、会话 ID、生成时间与使用边界声明

## 一句话原理

分层、分环节、分级、分门槛都有文献支撑；档与档之间的具体比例没有，属经验赋值。教师追问时如实说明，不要把「分层有据」说成「赋值有据」。详见 `references/model-rationale.md` 第八节。
